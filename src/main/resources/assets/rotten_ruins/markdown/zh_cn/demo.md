# 废墟调查手册

出发前请清点**照明物资**，为撤离留出*备用路线*。地图上标记为 ~~安全~~ 的路段仍需重新检查。

跳到[随身装备](#随身装备)，或查看 [Markdown 语法参考][commonmark]。

> 记录入口朝向和最近的地标。走过岔路后，回头确认标记仍然可见。
>
> > 如果返回路线被封，沿最后一个确认过的标记撤离。

## 出发检查

1. 校对地图。
   - 标记入口和最近的出口。
   - 记下两条路线的交汇点。
2. 检查法杖。

- [x] 已记录地表坐标
- [ ] 已确认撤离路线

### 记录坐标

把 `入口方向` 和 `集合点` 写在同一条记录里。下面的字段可抄进自己的笔记。

```text
入口方向：北
集合点：入口外的石柱
撤离路线：
    上层长廊 → 东侧出口
```
