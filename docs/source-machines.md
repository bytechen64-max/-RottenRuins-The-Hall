# 源荷滤波器与集荷器

两种设备的临时几何模型在 `src/main/resources/assets/rotten_ruins/models/block/` 中手动维护，
分别为 `source_filter.json` 和 `source_collector.json`，可直接导入 Blockbench 修改。
datagen 引用这两份模型来生成方块朝向和物品模型，后续生成不会覆盖模型本体。
滤波器是带铜线圈的金属机箱，集荷器是带蓝色储罐的机箱；模型默认北面输出、南面输入。
位于创造栏的“魔法”分区，注册名分别为 `rotten_ruins:source_filter` 和 `rotten_ruins:source_collector`。

## 放置与连接

设备只有前、后两个水平开口：背面的蓝口输入，正面的橙口输出，放置时输出朝玩家面向的方向。
空手潜行右键旋转 90°；普通右键打开界面，旋转和关闭界面都会保留物品与参数。

沿势流方向连接：

```text
高势区接地桩 → 源导线 → [蓝口 滤波器 橙口] → [蓝口 集荷器 橙口] → 源导线 → 非高势区接地桩
```

两台设备可以直接相连，也可以用源导线隔开。侧面不导通，反接不能形成有效回路。
设备和导线都会计入沿线最短路径的衰减距离，仍按每 4 格降低 1 档、最低 1 档计算。
不强制加载远处区块。断线、拆桩、旋转和调参会重新校验回路；已卸载部分不参与灌注。

## 滤波器

界面有“手动调谐 / 懒人模式 / 波段表”三个页签，使用与魔法装载界面一致的圆角面板。
懒人模式直接点击光、火、水、自然、死亡、虚空、神秘即可一次配置全部四个参数，采用下表的窗口中心设置。
虚空会自动切到反相；点击“手动微调”可继续修改预设。配置仍由服务端验证、保存，并使用有效电路灌注。

`fc`、`B`、`G` 的范围均为 0–10，步长 0.1；`φ` 只有正、反两档。
鼠标拖动或聚焦滑块后按左右键调节。参数由服务端验证并保存，客户端示波仪即时显示频率、幅值、脉冲或阻尼的变化。
“波段表”按钮可显示下表，所有范围均包含两端。

| 元素 | fc | B | G | φ | 一组可用设置 |
|---|---|---|---|---|---|
| 光 | 9–10 | 1–2 | 2–3 | 正 | 9.5 / 1.5 / 2.5 / 正 |
| 火 | 7–8 | 2–3 | 7–8 | 正 | 7.5 / 2.5 / 7.5 / 正 |
| 水 | 5–6 | 4–5 | 4–5 | 正 | 5.5 / 4.5 / 4.5 / 正（默认） |
| 自然 | 3–4 | 3–4 | 4–5 | 正 | 3.5 / 3.5 / 4.5 / 正 |
| 死亡 | 2–3 | 7–8 | 4–6 | 正 | 2.5 / 7.5 / 5.0 / 正 |
| 虚空 | 0–1 | 6–7 | 1–3 | 反 | 0.5 / 6.5 / 2.0 / 反 |
| 神秘 | 0–1 | 8–10 | 0–1 | 正 | 0.5 / 9.0 / 0.5 / 正 |

在有效元素窗口之外，示波仪显示未匹配，集荷器暂停。光为高相干细波，火为脉冲，水为连续波，
自然为稳定复合波，死亡为阻尼波，虚空为反相势阱，神秘为近静场。

## 集荷器

左槽放普通储魔瓶，右槽取出元素储魔瓶，支持 Shift 快速转移。
漏斗自动化：上方或侧面漏斗向输入槽送入普通空储魔瓶，下方漏斗只从输出槽抽取元素成品瓶。
下方不能抽走输入槽的原料，输出槽不能由漏斗塞入物品；滤波器没有物品槽，不接受漏斗输入。
每完成一轮只消耗 1 个空瓶并产出 1 个对应元素的储魔瓶；满瓶不能放进输入槽。
输出放不下或装着另一种元素瓶时暂停，物品不会被覆盖。

需要有效高低势回路，并从输入方向找到最近的上游滤波器。
同距上游滤波器的元素或增益冲突时暂停；串联多个滤波器时使用最后一个滤波器的设置。
断电、无效窗口或输出堵塞会暂停进度；切换到另一有效元素、取走输入瓶会清零进度。
存档保存物品、参数与进度，重新加载后先验证回路再继续。

进度满值为 3000 工作单位；每刻增加 `max(1, 强度 × (10 + 十倍增益) / 60)`，
距离越远速度越慢，同一元素窗口内增益越高速度越快；神秘的零增益仍有最低测量级灌注速度。

## 基础配方

以下配方均由 datagen 生成，每次产出 1 个。

- 普通储魔瓶：玻璃瓶 + 铜锭 + 源荷砂，无序合成。
- 滤波器：上排“铁锭 / 玻璃 / 铁锭”，中排“铜锭 / 扫描芯片 / 铜锭”，下排“铁锭 / 源导线 / 铁锭”。
- 集荷器：上排“铁锭 / 玻璃 / 铁锭”，中排“铜锭 / 提取芯片 / 铜锭”，下排正中放漏斗。
- 源荷板材（`source_mana_plate`）：上、下各 1 铜锭，左、右各 1 铁锭，中心 1 源荷砂，产出 1 块。
- 七系魔法板材：中心放 1 源荷板材，周围八格全部放同一种元素储魔瓶，产出对应的 1 块魔法板材，并返还 8 个普通空储魔瓶。
  光、火、水、自然、死亡、虚空、神秘均有各自配方，混用元素或缺少瓶子时不能合成。

## 生产线成就

原有“魔法，轻而易举啊！”分支下新增 14 个成就，均由 datagen 生成。

| 路线 | 成就 | 触发条件 |
|---|---|---|
| 勘测 | 看不见，测得到 | 获得简易场强计 |
| 勘测 | 势在必得 | 携带场强计进入高势区，每秒检查一次 |
| 勘测 | 脚踏实地 | 获得接地桩 |
| 生产 | 这回不是红石 | 获得源导线 |
| 生产 | 给混沌分个频 | 获得源荷滤波器 |
| 生产 | 对上频道 | 在滤波器界面提交任一有效元素窗口，支持手动与懒人模式 |
| 生产 | 反着来 | 在滤波器界面提交有效的虚空反相窗口 |
| 生产 | 收得住，才算本事 | 获得集荷器 |
| 生产 | 有来有回 | 打开已接入有效高低势回路的滤波器或集荷器 |
| 生产 | 把势流装进瓶子 | 获得任意元素储魔瓶 |
| 生产 | 七色收藏家 | 累计获得全部七系储魔瓶，挑战型成就 |
| 板材 | 万法之基 | 获得源荷板材 |
| 板材 | 魔法有了形状 | 获得任意元素魔法板材 |
| 板材 | 万象归板 | 累计获得全部七系魔法板材，挑战型成就 |

七系收藏采用七个独立条件累计，不要求同时占用背包槽位；已消耗的瓶子或板材仍计入进度。
物品获取类成就以进入玩家背包为准，自动化生产后需从输出容器中取出对应物品。

## 验证

`gradlew runData --offline` 生成资源与配方。
`gradlew copyPatchedMods runGameTestServer --offline` 验证支撑、导线、七种元素瓶转换、存档、参数边界、方向性和真实电路灌注。
独立参数窗口、预设、有向网络求解和曲线抗锯齿测试位于 `tools/tests/`。
离屏 GUI 预览：先将 `ElementBand.java` 与 `SourceWaveform.java` 编译到 `build/circuit-test`，
再执行 `tools/gui-preview/gui_preview.cmd -Scene source_machines -Time 2`。
预览使用英文 MC 位图字体，并生成手动、懒人、波段表和集荷器四张图；
它复用实机的波形采样与抗锯齿线带，容器槽位与交互状态为模拟。
