§ 语法提示

命名空间语法（默认）短别名（可选）效果
§[rrs:grad]
§[rrs:grad:#6FBF4A:#8B1E2D]		§g渐变·腐化
§[rrs:rainbow]§h彩虹流彩
§[rrs:pulse]§p呼吸
§[rrs:solid:#E8E4D8]—（无别名）苍白 / 纯色
§[rrs:shake]§s抖动
§[rrs:wave]§w波浪
§[rrs:glitch]§q故障
§[rrs:type]§t打字机
§[/] 或 §[/grad]§[/]关闭 / 重置效果
为什么用命名空间？ 原版 MC 的 § 是单字符格式码，裸单字母很容易和 Bedrock 材质色码、Phoenix / Brilliant Text 等 mod 的语法冲突。 方案默认使用 §[rrs:…]，短别名仅在配置开启时生效。
叠加：上色类（grad / rainbow / pulse / solid）与运动类（shake / wave / glitch / typewriter）可以叠加， 例如 §[rrs:grad]…§[rrs:shake]…§[/]。关闭标记 §[/] 之后恢复默认白字。

本页面是方案级视觉预览，非游戏内真实渲染：字形来自系统字体二值化，实际游戏内以 MC 像素字体 + 阴影为准； GIF 版本为 20 fps / 256 色调色板采样，本页为实时真彩渲染，观感可能略有差异。

公式与默认参数见 README.md 的公式表；生成脚本 generate.py（Pillow）与页面内 JS 使用相同数学。 §q 的颜色通道偏移在纯白字色下不可见（R/B 交换对白色无效、+0.35 青色会被截断为白）， 可在本页输入 §[rrs:grad]…§[rrs:glitch]… 观察色偏。
