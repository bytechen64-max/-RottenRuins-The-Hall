## 3. 语法：命名空间（默认）与短别名（可选）

方案最终采用**命名空间语法**，避免与 Bedrock 材质色码、Phoenix、Brilliant Text 等 mod 的裸单字母码冲突。
短别名是**配置项**，默认关闭。

| 效果 | 命名空间语法（默认） | 短别名（可选，默认关） |
|---|---|---|
| 渐变·腐化 | `§[rrs:grad]`，可指定颜色：`§[rrs:grad:#6FBF4A:#8B1E2D]` | `§g` |
| 彩虹流彩 | `§[rrs:rainbow]` | `§h` |
| 呼吸 | `§[rrs:pulse]` | `§p` |
| 苍白 / 纯色 | `§[rrs:solid:#E8E4D8]` | —（无别名） |
| 抖动 | `§[rrs:shake]` | `§s` |
| 波浪 | `§[rrs:wave]` | `§w` |
| 故障 | `§[rrs:glitch]` | `§q` |
| 打字机 | `§[rrs:type]` | `§t` |
| 关闭 / 重置 | `§[/]`，或按名关闭 `§[/grad]` | `§[/]` |

* 效果标记**作用于其后文字**，可连续叠加：`§[rrs:grad]…§[rrs:shake]…§[/]`。
* 上色类（grad / rainbow / pulse / solid）改写「当前颜色」，运动/显现类（shake / wave / glitch / type）叠加位移或可见性。
* 旧方案稿中的 `§i` 已并入 `§[rrs:solid:#E8E4D8]`；短别名表未提供 `i`。
* 预览解析器为简化实现：不支持嵌套方括号与转义，未知 § 码会被跳过不渲染；游戏内最终解析以 mod 实现为准。

## 4. 公式表（方案默认参数）

`t` 秒；`i` 字序；`n` 字总数；坐标单位 GUI px；颜色运算在 0..1 RGB 空间。

| 效果 | 默认参数公式 |
|---|---|
| **§[rrs:grad] 渐变·腐化** | `p = i/(n−1)`；`A=#6FBF4A`（腐化绿）→ `B=#8B1E2D`（王庭血红）；**线性光 RGB** 插值（sRGB→linear → lerp → sRGB）。静止，不随时间变化。 |
| **§[rrs:rainbow] 彩虹流彩** | `hue = (i·0.055 + t·0.12) mod 1`；`S = 0.72`；`V = 1.0`；HSV→RGB。 |
| **§[rrs:pulse] 呼吸** | `k = 0.65 + 0.35·(0.5 + 0.5·sin(2π·(t·0.8 + i·0.03)))`；`RGB ← 当前颜色 × k`。 |
| **§[rrs:solid:…] 苍白** | 固定色 `#E8E4D8`（可传自定义色）。 |
| **§[rrs:shake] 抖动** | `dx = 1.3·sin(11t + 2.1i) + 0.7·sin(17.3t + 5.7i)`；`dy = 1.3·sin(13.7t + 1.3i) + 0.7·cos(19.1t + 3.9i)`；结果保留 1 位小数；亚像素绘制（不做整像素跳变）。 |
| **§[rrs:wave] 波浪** | `dy = 1.6·sin(0.55i − 4.0t)`；`dx = 0`；1 位小数。 |
| **§[rrs:glitch] 故障** | `b = ⌊12t⌋`；`h = hash01(i, b, salt=1)`；当 `h < 0.10` 时该字：`dx = ±(3 + 4·frac(dir))`（3~7 GUI px）、`alpha ×= 0.55`、颜色通道偏移（`R/B 交换` 或 `逐通道 +0.35 青色`，clamp 到 1）。其余时间正常。 |
| **§[rrs:type] 打字机** | 周期 `3.2 s`；相位 `phase = t mod 3.2`；`phase < 1.6` 时显示前 `⌊12·phase⌋` 个字（12 字/s），`phase ≥ 1.6` 时全部显示；**未显示的字不绘制**（不是透明，连阴影也不画）。 |
| **组合** | 例如 `§[rrs:grad]…§[rrs:shake]…`：渐变按 `i` 上色，同时抖动；按 § 码出现顺序累加。 |

### 4.1 sRGB ↔ 线性光（§g 用）

```
sRGB → linear :  c ≤ 0.04045 ? c/12.92 : ((c + 0.055)/1.055)^2.4
linear → sRGB :  c ≤ 0.0031308 ? 12.92·c : 1.055·c^(1/2.4) − 0.055
```

在 sRGB 空间直接 lerp 会让「绿→红」中段发灰；在线性光空间插值后中段呈暗橄榄/黄褐过渡，
这正是腐化色（腐绿 → 王庭血红）想要的过渡。联络表右上角的色条即该插值结果。

### 4.2 确定性 hash（§q 用，`generate.py` 与 `index.html` 逐位一致）

```
hash_u32(i, b, salt):
    x = (i·374761393 + b·668265263 + salt·2246822519 + 0x9E3779B9) mod 2^32
    x = ((x XOR (x >> 13)) · 1274126177) mod 2^32
    x = x XOR (x >> 16)
hash01 = hash_u32 / 2^32        // salt=1 触发判定, salt=2 方向/幅度, salt=3 色偏模式
```

JS 侧用 `Math.imul` + `>>> 0` 实现同样的 32 位无符号运算，已做 240 组逐值交叉验证。

### 4.3 参数来源

* §g 的 A/B 色值、§h 的 0.055 / 0.12 / S / V、§p 的 0.65 / 0.35 / 0.8 / 0.03、§s 的两个正弦系数、
  §w 的 1.6 / 0.55 / 4.0、§q 的 12 Hz 分桶 / 0.10 概率 / 3~7 px / 0.55 alpha / 0.35 青色、
  §t 的 3.2 s / 1.6 s / 12 字每秒 —— 全部来自方案默认值（用户方案文档）。
* 预览侧的表示参数（不属于效果公式）：画布 240×44 GUI、3× 放大、SimHei 16 px、1 px 字间距、
  阴影 ×0.25、背景 #151015、20 fps、GIF 调色板 256 色 + Floyd–Steinberg 抖动。
* 短别名 letter 映射按最新方案：`g/h/p/s/w/q/t`，纯色无别名。

## 5. 帧数 / 时长 / 循环衔接

| GIF | 渲染帧 @20fps | GIF 编码后帧数 | 总时长 | 循环接缝说明 |
|---|---|---|---|---|
| gradient.gif | 1 | 1 | 2400 ms | 静止，无接缝 |
| rainbow.gif | 64 | 64 | 3200 ms | 循环时 hue 相位差 0.12×3.2 = **0.384**，首尾颜色有一次跳变；游戏内连续时间不受影响 |
| pulse.gif | 50 | 50 | 2500 ms | 2.5 s = **恰好 2 个** 1.25 s 呼吸周期，无缝 |
| pale.gif | 1 | 1 | 2400 ms | 静止，无接缝 |
| shake.gif | 48 | 48 | 2400 ms | 多频正弦不成整数周期，循环处有轻微跳变（预览时长限制所致） |
| wave.gif | 64 | 64 | 3200 ms | `t·4` 与 4π 差约 0.23 rad，接缝位移差 ≲0.4 GUI px，基本不可见 |
| glitch.gif | 50 | **22** | 2500 ms | 分桶 hash 不闭合，接缝表现为一次重新洗牌（符合故障观感） |
| typewriter.gif | 64 | **18** | 3200 ms | 一整周期；结束→重新逐字显现，属预期行为 |
| combo.gif | 48 | 48 | 2400 ms | 同 shake，轻微跳变 |

**为什么 glitch / typewriter 的 GIF 编码帧数少于渲染帧数？**
Pillow 编码 GIF 时会把**连续完全相同的帧合并**（累加该帧 duration）。故障效果中大量 1/12 s 分桶内没有触发字、
打字机后半段全部显示——这些帧视觉完全相同，因此被合并。**总时长与 20 fps 播放观感不变**；
`generate.py` 的自检按「累计 duration == 渲染帧数 × 50 ms」校验。

## 6. 与游戏内实际效果的差异（重要）

1. **字体不同**：预览用 SimHei 16 px 二值化近似 MC 像素字体。MC 的 ASCII 字形是 5 px 宽 + 1 px 间距的
   点阵，中文走 unifont 类字形，字宽/标点/基线都与 SimHei 不同；标题在游戏内会**更窄、更「方块」**。
   最终观感必须以游戏内截图为准。
2. **阴影**：预览按「右下 1 GUI px、主色 ×0.25」绘制，与 MC 原版暗影的思路一致；但 MC 对带 alpha 的
   文字、发光/描边等场景有额外处理，需进游戏确认。
3. **亚像素**：预览在 3× 图像分辨率下做双线性亚像素位移，所以抖动/故障/波浪的移动是平滑的；
   MC 的 `FontRenderer` 以整数像素栅格绘制，建议在游戏内用 float 坐标实测是否真的产生亚像素过渡，
   否则可能出现「整像素跳变」。
4. **§q 的颜色通道偏移在纯白字上不可见**：
   * `R/B 交换` 对白色 `(1,1,1)` 是恒等；`逐通道 +0.35 青色` 会被 clamp 回白色。
   * 因此 `glitch.gif` 在默认白字上主要呈现**位移 / 闪烁 / 半透明**，看不到色偏。
   * 若希望色偏可见：把 §q 叠在 §g / §i 之后（在 `index.html` 里输入
     `§[rrs:grad]…§[rrs:glitch]…` 可直接观察 R/B 交换效果），或把公式改成
     `c ← c·(1−0.35) + cyan·0.35` 的混合式。**这一点建议在方案定稿前确认。**
5. **命名空间语法需要 mod 解析层**：原版 MC 的 § 只识别单字符格式码（颜色 a-f、格式 k-o、r 等），
   `§[rrs:…]` 必须在文本解析/渲染层自行拦截；注意不要与其它 mod 的文本语法互相抢先解析。
   短别名默认关闭正是为了避免冲突。解析器还应约定：不支持嵌套、未闭合标记的作用范围到行尾。
6. **emoji**：预览浏览器/系统字体可能显示彩色 emoji，但 MC 内置字体没有 emoji 字形，游戏内会缺字；
   方案文本不建议依赖 emoji。
7. **GIF 是有限色板 + 20 fps 采样**：渐变/彩虹在 GIF 中可能出现轻微抖动噪点（256 色 + FS 抖动），
   游戏内为真彩色、逐帧渲染，会更顺滑。
8. **打字机时长**：17 字 × 12 字/s = 1.42 s，会在 1.6 s 揭示窗口结束前全部显示（提前约 0.18 s），
   属于公式与文本长度的自然结果；若要严格占满 1.6 s，可换更长文本或调整 cps。
9. **画布宽度**：预览固定 240 GUI px 宽。游戏内文本区域宽度取决于容器（tooltip / 标题 / 自定义 HUD），
   长行会换行或裁切，需按实际 UI 调整。
10. **静止效果的单帧 GIF**：`gradient.gif` / `pale.gif` 只有 1 帧是**正确的**（效果本身静止），
    部分播放器可能不显示 duration 元数据，但循环行为正常。

## 7. `index.html` 交互 playground

* **打开方式**：直接双击 `index.html` 用本机浏览器打开即可（`file://` 可用，无外网依赖、无 CDN、无字体下载）。
* **功能**：
  * 效果列表：8 个效果 + 组合示例按钮，点击切换整行效果；
  * 文本输入框：默认「腐朽之疫：王庭」，可直接内联写 § 码（命名空间或短别名均可），支持叠加与 `§[/]` 关闭；
  * 速度 / 幅度滑杆：预览参数（默认 1.00× = 方案默认值）；速度缩放 `t`，幅度缩放位移/呼吸深度；
  * 语法提示表：**命名空间语法（默认）** 与 **短别名（可选，默认关闭）** 两栏对照；
  * 实时 canvas：720×132（240×44 GUI × 3）逐字像素渲染，暂停/继续，显示当前 `t` 与解析出的效果栈。
* **解析器范围**：支持 `§[rrs:grad]`、带色 `§[rrs:grad:#AABBCC:#DDEEFF]`、`§[rrs:solid:#AABBCC]`、
  `§[/]`、`§[/grad]`、短别名 `§g §h §p §s §w §q §t`；不支持嵌套与转义，未知 § 码跳过。
* **说明**：页面是**实时真彩重建**，不是 GIF 播放；画面每分钟 60 帧更顺滑，公式与 GIF 完全一致
  （已通过 JS ↔ Python 572 项公式/解析交叉验证）。

## 8. 生成方式（可复现）

```bat

C:\Users\chy20\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe ^
```

* 坑：Windows 控制台非 UTF-8 时中文日志可能乱码（文件内容不受影响）；可在运行前设
  `set PYTHONIOENCODING=utf-8`。

## 10. 给审批者的 3 个注意点

1. **`combo.gif`** 是方案建议的默认叠加形态（渐变 + 抖动），观感最接近「标题在王庭腐化」的氛围。
2. **`glitch.gif`** 在纯白字上仅呈现位移/闪烁；若方案需要「色偏」可见，请确认第 6.4 节的公式调整。
3. **`typewriter.gif`** 用的是长副标题 + 12 GUI px 字号；若正式方案中打字机只用于短标题（16 px），
   节奏与占位会明显不同，建议用 `index.html` 改文本再确认。
