# 刀光工作台：三维预览与 JSON 效果

双击 `tools/start-slash-effect-editor.cmd`，浏览器打开本机的 `http://127.0.0.1:8765`。需要 Python 3.10+ 和 Pillow；当前开发环境已具备。旧锚点工具位于右上角“高级：锚点编辑”，正常调刀光不需要标点。

## 三步操作

1. 点击左上物品名称打开项目物品库，按中文名或资源 ID 搜索并点击图标；也可以勾选“仅已接入挥砍”。列表自动扫描当前项目模型 JSON、中文语言文件和物品注册源码，新增物品后点击“重新扫描”。再选“霜蓝新月 / 炽焰 / 像素铜光 / 雷光”预设。
2. 拖动滑块查看效果。拖动场景旋转，滚轮缩放；可以切换第一人称、自由视角、侧视，或暂停后拖动时间条。慢放只影响预览速度。
3. 展开“设置游戏实例目录”，填写实际游戏 `.minecraft` 的绝对路径并点设置；点击“保存到游戏配置”，回游戏按 **F3+T**。也可以导出 JSON 手动放入对应目录。

默认实例是项目 `run`。保存到模组资源用于开发和打包，需要重新构建模组；保存到游戏配置适合直接调试，不需要重编译。保存会备份上一次文件为 `.json.bak`。

## 参数

| 参数 | 作用 |
|---|---|
| 绘制方式 | 贴图刀光或着色器刀光 |
| 颜色、不透明度、亮度 | 改变颜色与可见强度，保留正常透明混合与世界深度遮挡 |
| 刀光宽度 | 外缘跟随实际刀尖，向内扩展扇面，不修改攻击范围 |
| 立体弧面 | 沿挥砍平面法线拱起；不根据相机转动整张刀光 |
| 残留时间 | 历史截面寿命，20 tick 为一秒 |
| 亮边宽度、扇面填充、柔光层 | 着色器的轮廓、内部覆盖与外围光晕强度 |
| 破碎与扰动、流动速度 | 着色器纹理的不规则程度与内部流动速度 |
| 拖尾收束 | 着色器中旧轨迹到新轨迹的强度变化 |
| 碎光数量 | 两种材质周围的碎光数量，0 为关闭 |
| 截面稳定 | 对邻近截面方向作平滑，保留大角度挥动，抑制褶皱 |
| 空气折射 | 背景采样位移强度，单位为 1080p 参考像素，随渲染目标高度缩放，0 关闭 |
| 折射色散 | 背景折射的红蓝分色程度 |

亮边/填充/柔光/扰动/流动/收束是着色器参数，贴图模式的形状和细节由 PNG 决定；宽度、弧面、颜色、亮度、不透明度、寿命与碎光对两种模式都生效。稳定、折射和色散也适用于两种模式。折射只沿三维刀光网格重新采样背景，空气带扩展到亮边外侧 18%，先复制干净背景、绘制折射，再绘制发光材质；每批共享一次场景拷贝，并保留深度遮挡；它不改变刀光顶点。Oculus 使用最终合成后的延迟入口，外部光影包观感仍需实机确认。柔光层是材质自身的宽亮区，不是全屏 Bloom。

## 文件位置

以天穹裁决为例：

- 游戏配置：`<游戏实例>/config/rotten_ruins/slash_effects/rotten_ruins/domerite_longsword.json`
- 模组或资源包：`assets/rotten_ruins/slash_effects/domerite_longsword.json`

游戏配置覆盖资源包/模组配置。工具载入时也按相同优先级读取；想恢复模组默认值，可以删除对应的本地覆盖文件后按 F3+T。

```json
{
  "version": 1,
  "renderer": "shader",
  "texture": "rotten_ruins:textures/effect/slash_crescent.png",
  "color": "#B2D9FF",
  "opacity": 0.96,
  "brightness": 1.65,
  "width": 1.9,
  "curvature": 0.035,
  "lifetimeTicks": 8,
  "coreWidth": 0.045,
  "fill": 0.65,
  "glow": 0.6,
  "noise": 0.3,
  "flowSpeed": 1.2,
  "tailPower": 1.3,
  "particles": 1,
  "stability": 0.85,
  "refraction": 9,
  "dispersion": 0.15
}
```

省略的字段采用默认值。`renderer` 也可填 `texture`，或用 `inherit` 沿用武器接口的材质选择；`color` 可用 `inherit` 沿用武器颜色。工具导出明确的颜色和材质，便于直观调试。纹理使用完整的资源 ID，工具从本地 assets 读取 PNG，游戏从当前资源包读取。

只有已实现 `ISlashWeapon` 且配置刀光锚点的武器才有这套效果；JSON 不会让普通物品获得攻击能力。效果 JSON 不修改伤害、冷却、命中或玩家动作。

## 预览与游戏的一致性

预览的刀光与空气折射着色器直接来自当前项目 `slash_trail.fsh`、`slash_air.fsh`，浏览器只转换 GLSL 接口语法；主要参数、宽度/弧面截面和透明混合语义与游戏一致。不是静态截图或预渲染视频。

剑使用物品实际 PNG 与刀根/刀尖标定。场景中的剑为简化的三维平面模型，挥砍为四向运动模拟。复杂元素模型、自定义动画、游戏 FOV、相机晃动及外部光影包可能改变最终观感，因此这里不承诺与每个游戏帧逐像素一致。高级工具仍可检查真实元素模型和调整锚点。

本轮四向实际武器挥动扩大为 140°，中段刀尖朝前、起止朝左右/斜向扫出。刀光与物品共用位姿。三个默认配置已提高亮度与扇面覆盖，降低弧面鼓起程度，并增加独立空气折射，游戏启动或资源重载时通过 `SlashEffects` 加载；本地旧配置会优先，因此若效果没有变化应先检查是否存在覆盖文件。

## 验证

- `python tools/tests/slash_editor_test.py`：锚点与效果 API、验证、路径边界、保存及 JSON 回读。
- `tools/tests/SlashEffectTest.java`：Java 解析、三种默认配置、JSON 往返、实际网格宽度与弧面变化。
- `tools/tests/slash-effects-browser.cjs`：开发用浏览器交互测试，检查宽度改变渲染像素、相机切换、预设、保存与导出。
- `./gradlew.bat -I tools/slash-client-smoke.init.gradle runClient --offline --console=plain`：真实客户端加载 JSON、shader，以及正式管线中的透明、遮挡、亮度参数和背景折射位移像素测试。

测试使用独立的游戏实例目录，不写入实际玩家存档。
