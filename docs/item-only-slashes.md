# 物品挥砍动画

挥砍已整合为 [ISlashWeapon 武器接口](slash-api.md)。只有实现接口的物品才启用范围攻击、挥砍动画和刀光；原先所有 SwordItem 自动生效的逻辑和 item_only_slash 包含／排除标签已移除。

当前接入：纯铜剑（像素贴图刀光）、多米勒特剑和天穹裁决（程序化着色器刀光）。其他武器保持原攻击与渲染。默认连招为右到左、左到右、右上到左下、左上到右下；可以逐武器配置。主手请求由服务端验证并同步结果，客户端不再根据普通挥手包独立计数。

动画数学保留在 client/rend/slash：

- 无挥砍时完全走原版手持渲染。
- 第一人称横砍保留原屏幕跨度；斜砍按与世界刀光一致的固定 45° 切割平面移动，宽高比／FOV 只调整轨迹长度，不改变角度。四种姿势的剑身长轴都朝向正前方，方向区别来自剑的移动，而非把剑尖抬起或压低。
- 每刀第一人称预备都从自身画面外起点进入，进入之前已经完成朝向调整；不会把上一刀的终点横向拉到下一刀起点，也不会在新刀零进度时插入一帧原版手持姿势。
- 第三人称主挥砍不跟随手臂，挥砍坐标同时跟随视线俯仰和头部朝向相对于身体的偏转；剑尖沿玩家视角前向，预备和回收衔接原版握持矩阵。
- 模型顶点 PCA 推断长轴和宽面法线，映射刃口到运动方向；不具有明显长轴／薄面或独立 Geo renderer 保留原物品渲染。
- 第一人称收招使用独立 11 tick 时间：离屏 1.8、停留 1.6、下移转向 1.2、下方换位 1.2、向上抬回 5.2。转向与横移在画面外完成，抬回阶段保持原版握持角度、X 和深度。
- 斜下砍通过下边缘时保持深度不变，沿原斜线继续出屏；完全隐藏后才做深度和朝向调整，避免刚穿过底部又因透视收缩而向上弹回。
- 配置 itemOnlySwordSlashes 仅开关本客户端的物品动画与刀光，不改变服务端攻击规则。
- 贴图和着色器刀光使用物品实际锚点的逐帧轨迹；第一、第三人称独立采样，都转换到世界坐标后按场景深度绘制，不再推算一条与剑分离的圆弧。可用[可视化锚点编辑器](slash-anchor-editor.md)在纹理或模型上标点，保存 JSON 后重载生效。

实现独立编写，没有导入 Better Combat 的动画资源或代码。原有几何／投影／归位测试继续适用；新范围算法、服务端测试和刀光 GPU 预览见接口文档。

像素风刀光的绘制、调色和替换见 [绘制说明](slash-trails/painting.md)。
